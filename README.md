# SJ Consultants - Overseas Education Consultancy

Official website for SJ Consultants, an overseas education consultancy founded by Shovik Julka.

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Setup & Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
